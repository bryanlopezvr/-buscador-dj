La aplicación incluye un sistema para consultar paquetes musicales publicados, visualizar su contenido y acceder a las descargas disponibles para usuarios Premium.

## 🚀 Tecnología

- **Electron + React + Vite** — aplicación de escritorio moderna.
- **Everything** — motor de búsqueda rápido para archivos locales.
- **BPM / Key Analysis** — análisis musical integrado.
- **Supabase** — autenticación y gestión de usuarios Premium.
- **GitHub Releases** — distribución y actualizaciones de la aplicación.
